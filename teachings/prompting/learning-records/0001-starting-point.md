# Starting point & mission established

Henry wants to become a genuinely skilled prompter, primarily to (a) steer Claude
Code reliably and (b) author skills / system prompts / `CLAUDE.md` files that
control Claude consistently. Fable-vs-Opus model selection is a secondary interest.

Despite being a sophisticated Claude Code power user (custom skills, LLM-maintained
wikis), he explicitly asked to **start from the basics** — so the floor is being
built deliberately, briskly, not assumed. This sets the zone of proximal development:
begin with foundational prompting principles applied to his real work, then climb to
intermediate/advanced (few-shot design, structured output, altitude/context control,
model-specific tuning, eval-driven iteration) and model selection.

Lesson 1 delivered: explicitness + intent ("say what you want, and why"). Not yet
demonstrated as learned — waiting for evidence (a rewrite of his own, or a diagnosis
of a real failed prompt) before promoting mastery.
