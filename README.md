# skills

Personal agent skills for Claude Code and Codex.

## Skills

| Skill | Description |
|-------|-------------|
| [orchestration-bootstrap](orchestration-bootstrap/SKILL.md) | Set up a file-driven Codex/Claude orchestration workflow in an existing repository |

## Usage

Skills can be used directly by pointing Claude Code or Codex to this directory, or by copying individual skill directories into `~/.claude/skills/` or `~/.agents/skills/`.
